Om mig

Jag heter Sam och har arbetat som junior molnadministratör. Där lärde jag mig att drifta, övervaka och säkra infrastruktur i Azure, och att automatisera allt som går att automatisera.

Nu utbildar jag mig till blockchainutvecklare. Säkerhet, spårbarhet och system som ska gå att lita på är lika viktiga i en blockkedja som i en molnmiljö, så min bakgrund ger mig en bra grund. Just nu lär jag mig Solidity och hur smarta kontrakt testas och driftsätts.

Jag gillar att förstå hur saker fungerar på djupet, från nätverket och servern hela vägen upp till kontraktet som körs på kedjan.

Mycket av min inläsning gör jag i Ethereums utvecklardokumentation på ethereum.org (öppnas i en ny flik).

Projekt

Tre projekt från min tid med molnplattformar, där jag har byggt, styrt och optimerat miljöer.

Azure · Infrastructure as Code

Three-Tier Architecture + Infrastructure as Code

En trelagersarkitektur med webb, applikation och databas i Azure, uppsatt helt med kod. Nätverket är uppdelat i separata subnät med NSG-regler, så att databasen bara kan nås från applikationslagret. Hela miljön kan rivas och byggas upp igen med ett kommando.

Azure + AWS · FinOps

Multi-Cloud FinOps and Cost Optimization System

Ett system för att följa upp och sänka molnkostnader i både Azure och AWS. En gemensam taggstrategi, budgetlarm och månadsrapporter visar vad varje miljö kostar och var det finns pengar att spara, till exempel oanvända resurser och för stora virtuella maskiner.

Identitet · Styrning

Enterprise Hybrid Identity & Azure Arc Governance

Synkroniserade identiteter mellan ett lokalt Active Directory och Microsoft Entra ID, och Azure Arc för att styra lokala servrar från Azure. Azure Policy och RBAC ger samma regler för säkerhet och åtkomst, oavsett om servern står i molnet eller i ett serverrum.
